# Web Development Learning Path

## Beginner Stage
Start with HTML and CSS fundamentals. Learn how to structure web pages using semantic HTML
tags, and style them using CSS including flexbox and grid layouts. Build 2-3 static websites
such as a portfolio page or a landing page to practice.

## JavaScript Fundamentals
After HTML/CSS, move to core JavaScript concepts: variables, functions, loops, conditionals,
DOM manipulation, and event handling. Practice by building small interactive projects like a
to-do list, a calculator, or a simple quiz app.

## Intermediate Stage: Frontend Framework
Learn React.js. Understand components, props, state, hooks (useState, useEffect), and routing
with React Router. Build a multi-page project such as a weather app or a movie search app that
consumes a public API.

## Backend Basics
Learn Node.js and Express.js to build REST APIs. Understand routing, middleware, and how to
connect a backend to a database like MongoDB using Mongoose. Practice by building a CRUD API
for a simple app such as a blog or notes app.

## Full-Stack Integration
Combine frontend and backend into a full MERN stack project. Learn authentication using JWT,
password hashing with bcrypt, and role-based access control. A good practice project is a
URL shortener or a task manager with user accounts.

## Advanced Stage
Learn about deployment (Render, Vercel, or Railway), environment variables, and basic DevOps
concepts like Docker containers. Also explore testing basics and version control workflows
with Git and GitHub, including branching strategies.

## Recommended Project Progression
1. Static portfolio site (HTML/CSS)
2. Interactive JS project (to-do list or calculator)
3. React project consuming a public API
4. Full CRUD REST API with Express and MongoDB
5. Full-stack MERN project with authentication
6. Deployed full-stack project with basic DevOps setup
