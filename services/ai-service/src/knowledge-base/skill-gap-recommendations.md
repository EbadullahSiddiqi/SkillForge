# Skill Gap Recommendations

## If Git and Version Control is Missing
A student without Git knowledge should start by learning basic commands: init, add, commit,
push, pull, and clone. Next, practice branching and merging using a personal project. Create
a GitHub account, push a small project, and practice writing clear commit messages. Understanding
pull requests and resolving merge conflicts is the next milestone.

## If Web Development Basics are Missing
A student missing web development fundamentals should begin with HTML and CSS before moving to
JavaScript. Building 2-3 static pages is a good starting point, followed by a small interactive
project using vanilla JavaScript such as a to-do list or calculator, before moving to any framework.

## If Backend Development is Missing
A student without backend experience should learn a server-side language or runtime (such as
Node.js) along with a framework (such as Express.js). Understanding how to build REST APIs,
handle HTTP requests, and connect to a database is essential. A recommended starting project
is a simple CRUD API for notes or tasks.

## If Database Knowledge is Missing
A student missing database skills should first learn relational database basics (tables, keys,
joins) using SQL, then explore a NoSQL database such as MongoDB. Practicing schema design and
writing basic queries (SELECT, INSERT, UPDATE, DELETE for SQL; find, insertOne, updateOne for
MongoDB) builds a solid foundation.

## If DevOps Basics are Missing
A student missing DevOps fundamentals should start with basic Linux command line usage and
shell scripting. Next, learn Docker: creating a Dockerfile, building an image, and running a
container. Afterward, a light introduction to Kubernetes concepts (pods, deployments, services)
and infrastructure-as-code tools like Terraform is recommended, without needing to master
production-scale infrastructure immediately.

## If AI/Machine Learning Knowledge is Missing
A student missing AI fundamentals should start with Python basics if not already comfortable,
then move to using pretrained AI model APIs before attempting to train models from scratch.
Learning prompt engineering and how to integrate an AI API into a simple application is a
practical first milestone, followed by exploring RAG and agent-based AI concepts.

## If Authentication and Security Basics are Missing
A student missing security fundamentals should learn about password hashing (e.g., bcrypt),
token-based authentication (JWT), and role-based access control. Practicing by adding login,
registration, and protected routes to a small existing project is an effective way to learn
this hands-on.

## General Approach for Any Skill Gap
Identify the specific missing sub-skill rather than a broad topic, find one small practical
project that directly requires that sub-skill, complete it end-to-end, and only then move to
the next related concept. Building projects rather than only watching tutorials leads to faster
and more durable skill acquisition.
