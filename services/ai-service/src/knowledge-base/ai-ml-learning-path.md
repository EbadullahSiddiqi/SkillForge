# AI/ML Learning Path

## Prerequisites
Before starting AI/ML, a learner should be comfortable with Python fundamentals including
variables, functions, loops, data structures (lists, dictionaries), and object-oriented
programming basics. Basic understanding of mathematics (linear algebra, probability, and
statistics) is also helpful but can be learned alongside.

## Beginner Stage: Python for Data
Learn core Python libraries used in AI/ML: NumPy for numerical operations, Pandas for data
manipulation, and Matplotlib for basic data visualization. Practice by analyzing small
datasets, such as cleaning a CSV file and creating simple charts.

## Machine Learning Fundamentals
Learn core ML concepts: supervised vs unsupervised learning, regression, classification,
and basic model evaluation metrics (accuracy, precision, recall). Use scikit-learn to build
simple models such as a linear regression predictor or a spam classifier.

## Intermediate Stage: Deep Learning Basics
Learn the fundamentals of neural networks: layers, activation functions, forward and backward
propagation, and training loops. Get hands-on with a framework such as TensorFlow or PyTorch.
Build small projects like a digit recognizer using the MNIST dataset.

## Working with APIs and Pretrained Models
Learn to use pretrained AI models through APIs (such as language models or vision models)
rather than training from scratch. This includes understanding prompts, tokens, and how to
structure API requests and responses. A good practice project is building a simple chatbot
or text summarizer using an existing model API.

## Generative AI and LLMs
Learn the basics of how large language models work at a conceptual level, prompt engineering
techniques, and how to use LLM APIs effectively in an application. Explore concepts such as
temperature, max tokens, and system prompts.

## RAG and Agentic AI (Applied AI Engineering)
Learn how Retrieval-Augmented Generation works: converting text into embeddings, storing them
in a vector database, and retrieving relevant context before generating a response. Also learn
the basics of AI agents: giving a model access to tools/functions it can call to complete tasks
rather than only generating text.

## Advanced Stage: AI in Production
Learn how to deploy AI-powered applications, including basic considerations like latency, cost
management for API calls, and containerizing AI services with Docker. Explore MLOps concepts
at a beginner level if pursuing further specialization.

## Recommended Project Progression
1. Data analysis project using Pandas and Matplotlib
2. Simple classifier or regression model using scikit-learn
3. Small neural network project (e.g., digit recognition)
4. Chatbot or assistant built using an LLM API
5. RAG-based application answering questions from a custom knowledge base
6. AI agent that uses at least two tools to complete a task
