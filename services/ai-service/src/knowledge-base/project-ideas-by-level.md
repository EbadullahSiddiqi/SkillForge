# Project Ideas by Skill Level

## Beginner Level Projects
These projects help build fundamentals and typically take a few days to complete.
- To-Do List application using vanilla JavaScript or a basic framework
- Simple Calculator with basic arithmetic operations
- Static personal portfolio website using HTML and CSS
- Rock Paper Scissors game using JavaScript
- Basic Weather App that fetches data from a public weather API
- Tic-Tac-Toe game with simple win-detection logic

## Intermediate Level Projects
These projects combine multiple concepts such as APIs, state management, and basic backend work.
- Movie or Book Search App using a public API with search and filter functionality
- Blog Application with a Node.js/Express backend and MongoDB, supporting create, read, update,
  and delete operations
- Expense Tracker with charts showing spending by category
- GitHub Profile Finder that fetches and displays public GitHub user data
- URL Shortener with authentication and click tracking
- Typing Speed Test with real-time feedback and scoring

## Advanced Level Projects
These projects require full-stack thinking, authentication, and often deployment.
- Full-Stack Task Management App with user roles (e.g., admin and regular user), authentication,
  and role-based permissions
- E-commerce Product Catalog with cart functionality, filtering, and a backend API
- Event Booking Platform with role-based access for organizers and attendees
- Real-Time Chat Application using WebSockets
- Job/Internship Board with search, filters, and application tracking

## AI-Integrated Projects
These projects are well-suited for learners moving into applied AI engineering.
- Chatbot that answers questions using a Large Language Model API
- Document Q&A Assistant using Retrieval-Augmented Generation over a small set of PDFs or text files
- AI-Powered Recommendation System that suggests content or resources based on user input
- AI Agent that can use at least two tools (for example, searching a database and performing
  a calculation) to complete a multi-step task
- Resume/CV Analyzer that extracts skills and suggests improvements using an AI model

## DevOps and Deployment Practice Projects
These projects help build practical DevOps skills alongside an existing application.
- Containerize an existing full-stack project using Docker and Docker Compose
- Write Kubernetes manifests (Deployment and Service) for a small multi-service application
- Set up a basic CI pipeline that runs tests automatically on every push
- Write a basic Terraform configuration to define infrastructure for a simple deployment
- Write a shell script that automates project setup (installing dependencies, starting services)

## How to Choose a Project
A learner should choose a project slightly above their current comfort level, one that
requires learning one or two new concepts while reusing skills they already have. Completing
smaller projects end-to-end, including basic deployment, is more valuable for skill growth
than starting many large projects without finishing them.
